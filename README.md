## Announcement

Until now, this account and the **Oblivion** programming team have run experimental and educational projects: prototypes, learning exercises, and studies in algorithm design.

**That phase is complete.** Oblivion is now an official brand with a defined direction:

> **Develop and advance artificial intelligence. Build games. Ship rigorous, verifiable engineering.**

Our first and most important official project is **Angra**, and it is expected to grow substantially.

## Mission

| Area | Focus |

| **Game Development** | Games with real systems behind them: gameplay logic, NPC behavior, and dialogue systems. |
| **Algorithm Engineering** | Clean, efficient, documented code. Correctness before claims. |

## Angra — Flagship Project

**Angra** is Oblivion's first official project and the center of our roadmap.

Angra is an integration and orchestration layer that connects local AI tools into a single workflow. It is not an AI model, and it does not replace the tools it connects.

| Package | Connects to |
| :-- | :-- |
| `Angra.py` | LM Studio |
| `Angra2.py` | Bionic |

- Written in Python
- Open source, under the **ANGRA OSS** name
- Under active development, with a long road ahead

## Engineering Principles

1. **No fabricated results.** We do not publish benchmarks, sizes, or capabilities that we have not measured and verified.
2. **Real implementations.** If a feature is listed here, it exists. If it does not yet, it is marked as planned.
3. **Reproducibility.** Anyone running the code should be able to verify what we claim.
4. **Depth over hype.** We prefer to understand an algorithm fully before building on it.
